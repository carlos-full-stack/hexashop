# Hexashop

## Introduction

Full Responsive Ecommerce Store

## Features

- Show content on different devices: desktop, tablet and mobile.
- Show a hamburger menu on tablet and mobile devices.
- Show product in slider with animated icons for options.
- Use of BEM methodology to improve code maintenance and scalability.


## Tecnologies

Hexashop was created using JavaScript HTML and CSS (BEM)


## Install


1. Clone this repo
```bash
$ git clone https://github.com/carlos-full-stack/hexashop
```
